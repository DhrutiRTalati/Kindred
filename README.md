# Kindred

## Overview
Kindred is a social platform designed to strengthen human connections through a "social inventory" ledger. Instead of financial transactions, users exchange support, favors, and emotional help.

## Features
- User login system
- Dashboard interface
- Social interaction concept (Hearth)
- Frontend prototype of community-based support system

## Tech Stack
- HTML
- CSS
- JavaScript

## Status
This is a prototype demonstrating the concept and user interface.
